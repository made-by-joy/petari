# ペタリ (Petari)

コピーしたテキスト・画像・定型文をひとつの履歴にまとめる、Windows 用のクリップボード管理アプリです。無料で使えます。

- 紹介ページ: https://made-by-joy.github.io/petari/
- ダウンロード: https://github.com/made-by-joy/petari/releases/latest

## できること

- テキストの履歴: コピーした文章を順に保存し、選んで貼り直せます
- 画像の履歴: 画像をコピーしたあとに別の内容をコピーしても、画像のまま貼れます
- 定型文とフォルダ: よく使う文章をフォルダに分けて登録できます
- キーボードで完結: Ctrl を 2 回 (または Ctrl+Alt+V) で呼び出し、Enter で貼り付け

## 入れ方

1. 配布ページから `Petari-<版>-win-x64.zip` をダウンロードします
2. ZIP を右クリックして「すべて展開」を選びます
3. 展開したフォルダの `install.ps1` を右クリックして「PowerShell で実行」を選びます

コード署名を付けていないため、初回の起動時に Windows の警告が出ることがあります。「詳細情報」→「実行」で進めます。Smart App Control が有効な PC では起動できません。

## 動作環境

Windows 11 (64bit)。追加のインストールは要りません。

## プライバシー

コピーした内容は、暗号化して PC の中だけに保存します。ペタリに通信の機能はなく、外部へ送信しません。
